# Noise-Aware, Error-Budgeted Hybrid Workflow Scheduling

Reproducibility repository for **“Noise-Aware, Error-Budgeted Scheduling of Hybrid Quantum–Classical Workflows Using Time-Varying QPU Calibration Data.”** This project implements an event-driven simulator that evaluates a calibration-aware scheduler against four baselines.

> **Scope:** The calibration summaries are derived from public IBM Quantum properties. Workflows, arrivals, operation counts, deadlines, and service durations are generated by the simulator. No quantum circuits were submitted to hardware. The reported failure metric is an independent-operation error proxy, not measured circuit fidelity or a hardware reliability guarantee.

## Repository contents

```text
data/       Compact calibration summary used by the experiments
figures/    Manuscript figures in PNG and vector PDF
results/    Per-workflow, per-scenario, and aggregate CSV outputs
src/        Simulator, extraction/analysis scripts, and paper generator
paper.docx  Six-page IEEE-style manuscript
paper.pdf   Rendered manuscript
```

The largest included data file is the per-workflow output CSV (about 17.4 MB); every included file is below GitHub's 25 MiB browser-upload limit. The 105,303,760-byte source Parquet file is intentionally excluded because it exceeds GitHub's 100 MiB regular Git limit; it can be downloaded from the immutable source revision using the command below.

## Reproduce the reported run

Tested with Python 3.12.14. From the repository root:

```bash
python -m venv .venv
# Activate .venv for your operating system, then:
python -m pip install -r requirements.txt
python src/simulate.py
python src/validate_forecast.py
python src/diagnose_budget_feasibility.py
python src/plot_calibration.py
python src/plot_method.py
python src/make_paper.py
```

The simulator regenerates `results/`. The validation and diagnostic scripts regenerate their corresponding detailed and aggregate CSVs. The plot scripts regenerate the PNG/PDF figures. The paper generator rebuilds `paper.docx` from the calibration input and result CSVs; export it to PDF using Microsoft Word or LibreOffice for a local rendered copy.

The evaluation has five seven-day UTC calibration windows starting on 2026-02-15, 2026-04-15, 2026-06-15, 2026-08-15, and 2026-10-15; three workload seeds (17, 23, 42); arrival rates of 4 and 8 workflows/hour; and five scheduling policies. This yields 15 window/seed blocks per rate. Each generated workflow has three QPU tasks and four classical tasks. Table cells report mean and sample standard deviation over those blocks; these are descriptive summaries, not confidence intervals or hypothesis tests.

## Calibration data

`data/ibm_heron_calibration_snapshots.csv` is the 10,020-row derived input used in the reported run. It summarizes CZ-gate and readout error observations for `ibm_fez`, `ibm_kingston`, and `ibm_marrakesh`; it also retains component calibration-age summaries used by the scheduler's freshness rule.

The source is the Hugging Face dataset [phanerozoic/Qiskit Calibration Drift](https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift), pinned to revision `bfaaec7ee00a091b1710153e251f4c69e1ac9254`, distributed under CC BY 4.0. See [DATA_SOURCES.md](DATA_SOURCES.md) for attribution and extraction details.

To recreate the compact CSV from the full source file, install the pinned DuckDB dependency and download the Parquet file at that revision:

```bash
curl -L 'https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift/resolve/bfaaec7ee00a091b1710153e251f4c69e1ac9254/data/train-00000-of-00001.parquet' -o data/train-00000-of-00001.parquet
python src/extract_calibration.py
```

The raw Parquet file is excluded by `.gitignore`. Do not commit it to a normal GitHub repository; use the compact CSV or an external data repository if needed.
